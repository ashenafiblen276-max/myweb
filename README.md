
# Blen Ashenafi - Portfolio & Contact System

A modern, responsive full-stack portfolio website built with HTML5, CSS3, PHP (PDO), and MySQL.

## Features

- **Modern Dark UI:** Beautiful dark design with purple glow effects.
- **Responsive Design:** Works on mobile and desktop.
- **About Me:** Personal information and introduction.
- **Portfolio:** Showcases my skills and projects.
- **Contact & Inbox:** Visitors can send messages, stored in a MySQL database.

## Technologies Used

- HTML5
- CSS3
- PHP
- MySQL
- XAMPP

## How to Run

1. Start Apache and MySQL in XAMPP.
2. Place the project folder inside `htdocs`.
3. Open your browser.
4. Visit `http://localhost/folder-name/index.php`.
